Implementation Steps

1. Reuse the existing expression extraction settings:

- Expression Scope
- Node Lemma
- N-gram Length
- Minimum Expression Frequency
- Stoplist
- Lemmas

Do NOT create a separate extraction system.

2. For each speech / record:

- process tokens using existing processTokens()
- generate expression candidates using the same n-gram length logic
- apply the same scope logic:
  - Node-centred mode: keep n-grams containing node lemma
  - Corpus-wide mode: keep all eligible n-grams
- assign each expression occurrence to a time slice

3. Aggregate expression candidate frequencies by time slice.

Output fields should include:

- expression
- n / length
- total frequency
- first seen
- last seen
- slices present
- temporal behaviour

4. Define temporal behaviour descriptively.

Suggested categories:

- Persistent
- Emerging
- Declining
- Intermittent
- Transient

Use simple transparent rules.

Example rules:

Persistent:
appears in 3 or more slices and spans at least half of the available timeline

Emerging:
first appears after the first third of the timeline and continues into later slices

Declining:
appears early but not in the final third of the timeline

Intermittent:
appears in non-contiguous slices

Transient:
appears in only one slice

Keep the rules simple and documented in the UI.

5. For Expression Families view:

- reuse or reconstruct family patterns from expression candidates per slice
- aggregate family frequencies by slice
- calculate:
  - family pattern
  - total frequency
  - first seen
  - last seen
  - slices present
  - temporal behaviour

Do NOT change the family construction method.

6. Add a summary block for Section D.

Show:

- active diachronic object
- number of tracked items
- most persistent item
- most frequent item
- dominant temporal behaviour

7. Add a line chart or compact temporal trend table.

Preferred minimal implementation:

- table first
- optional simple line chart only if easy with existing Recharts imports

Do NOT introduce new charting libraries.

8. Add main table.

For Expression Candidates view:

Columns:

- Expression
- Length
- Total Frequency
- First Seen
- Last Seen
- Slices Present
- Temporal Behaviour

For Expression Families view:

Columns:

- Last Seen

9. Add row selection / drill-down.

Selecting a row should show its frequency by time slice.

Slice | Frequency

Optional:
small bar by frequency using existing CSS-only bar style.

10. Add CSV export.

For Expression Candidates view:

semantic_expression_change_candidates_<scope>_<nodeLemma-or-corpus>.csv

For Expression Families view:

semantic_expression_change_families_<scope>_<nodeLemma-or-corpus>.csv

CSV should export the currently displayed main table.
