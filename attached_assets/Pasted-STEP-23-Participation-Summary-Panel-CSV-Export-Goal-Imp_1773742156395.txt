Implementation Steps

1. Locate the Quad Subcluster Participation section in Analysis.tsx.

2. Add a compact Participation Summary block above the participation table.

3. The summary must show:
   - Total quads in current displayed participation view
   - Intra-subcluster count
   - Cross-subcluster count
   - Fringe count

4. Also show percentages for each of the three real participation categories:
   - Intra-subcluster
   - Cross-subcluster
   - Fringe

5. Percentages should be calculated against the currently displayed filtered participation rows, not the full underlying dataset.

6. Keep “Boundary” as a UI filter only.
   Do NOT treat Boundary as a fourth participation category in the summary.
   Boundary = Cross-subcluster + Fringe for filtering only.

7. Add an Export CSV button to the Quad Subcluster Participation panel header.

8. The export must download the currently displayed filtered rows only, respecting:
   - participation filter
   - row limit (Top 20 / Top 50 / All)

9. Export filename should be descriptive, for example:
   quad_subcluster_participation_<nodeLemma>_<filter>.csv

10. Export columns should match the currently displayed table columns:
   - quadKey
   - participationType
   - subclustersTouched
   - mappedCoTerms
   - unmappedCoTermsList
   - frequency

11. Keep the existing table and controls intact.
   Do NOT redesign the panel.
