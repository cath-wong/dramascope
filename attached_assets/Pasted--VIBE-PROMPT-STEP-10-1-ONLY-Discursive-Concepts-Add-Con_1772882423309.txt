Goal:

This must be a filtering option only.
The underlying quad extraction model must remain unchanged.

1) Add Discursive Filter Toggle

In the Discursive Concepts tab controls (near the node lemma input or exploration controls), add a toggle:

Show lemmas:
[ All Words ]  [ Content Words Only ]

Default = All Words (preserves current behaviour).

Store toggle state in DiscursiveTab:

contentWordOnly: boolean

2) Create a new utility file

Create:

client/src/utils/discursiveFilter.ts

This file defines a small function-word stoplist and helper utilities.

Add:

export const FUNCTION_WORDS = new Set([
"the","a","an","and","or","but","if","then","else",
"i","you","he","she","it","we","they",
"me","him","her","us","them",
"my","your","his","their","our","its",
"this","that","these","those",
"is","was","are","were","be","been","being",
"do","does","did","have","has","had",
"shall","will","would","should","may","might","must",
"to","of","in","on","at","by","for","from","with","about"
]);

export function isContentWord(token: string) {
  return !FUNCTION_WORDS.has(token);
}

Keep this list compact; we can expand later.

Filter lemmas before ranking in:
