STEP 26A — Discursive Tab UI Usability Pass (Collapsible Panels + Sticky Headers + Better Scroll Heights)

Goal

Improve the usability of the Discursive tab without changing any modelling logic.

This step should:
1. make long secondary/supporting panels collapsible
2. give long tables sticky/frozen headers inside scrollable containers
3. increase the visible height of short internal scroll boxes that currently show too few rows

This is a cosmetic and usability step only.


IMPORTANT

Do NOT modify, revert, overwrite, or refactor any manually edited code.
Do NOT change:
- quad extraction
- stoplists
- tokenisation
- lemmatisation
- Sankey logic
- subcluster generation logic
- participation logic
- temporal logic
- similarity calculations
- CSV export logic
- any summary logic added earlier

Only improve layout, scroll behaviour, and panel visibility.


Where to implement

Primary file:
- client/src/pages/Analysis.tsx

Use existing UI primitives where possible:
- Collapsible
- CollapsibleTrigger
- CollapsibleContent

Do NOT modify utility files in this step.


Implementation Steps

1. Keep the four main section headings visible and NOT collapsible:
   - Constellation Snapshot
   - Cluster / Configuration Profile
   - Concept Behaviour Summary
   - Diachronic Change View

2. Within those sections, make secondary/supporting panels collapsible.

3. Prefer the following default behaviour:

   KEEP OPEN by default:
   - Sankey Traffic (Synchronic Overview)
   - Constellation Subclusters
   - Participation Summary / main behaviour block
   - Diachronic Stability or Temporal Concept Flow (whichever is already more primary in the layout)

   COLLAPSE by default:
   - Recurring Co-Terms
   - Top Co-Term Pairings
   - full Quad Subcluster Participation table
   - Constellation Similarity / Distance
   - Constellation Similarity Matrix
   - Constellation Clusters
   - any other long supporting evidence tables

4. Add a clear trigger label for collapsed panels using the existing card title and a small chevron if convenient.

5. For long tables, wrap the table body area in a fixed-height scroll container and keep the table header sticky.

6. Apply sticky/frozen table headers to long tables where practical, especially:
   - Quad Subcluster Participation
   - Core vs Peripheral Quads
   - Constellation Similarity Matrix if applicable
   - any other tall tables already inside scroll containers

7. Use CSS classes or inline className adjustments only.
   Preferred approach:
   - add max-h / h to the scroll container
   - add overflow-y-auto
   - add sticky top-0 z-10 bg-background to header rows or header cells

8. Fix the “Top Shared Quads” and “Top Shared Co-lemmas” boxes in the Constellation Similarity / Distance panel:
   - increase their visible height so they show substantially more than 3 rows
   - target roughly 8–10 visible rows if data exists
   - keep scrolling if needed, but make the frame meaningfully taller

9. Do NOT reduce readability by making everything tiny.
   Use reasonable heights and preserve current typography where possible.

10. Do NOT collapse the main Sankey visual or remove any current content.
