5) Window definition (non-negotiable)

For each occurrence of the node lemma inside a speech’s token array:

windowStart = max(0, index - 50)

windowEnd = min(tokens.length, index + 51)

windowTokens = tokens[windowStart:windowEnd]

Overlaps are allowed (do not deduplicate overlapping windows).

This guarantees:

all co-lemmas are within 50 tokens of node

total span is bounded and interpretable

6) Co-occurrence counting (node-centred)

Within each node window:

Build counts of neighbour lemmas in that window excluding the node itself.

Aggregate across all node windows in the scope:

Maintain:

coocCount[lemma] += occurrences_in_window (count-based)
Also track:

windowHits[lemma] += 1 when lemma appears at least once in a window (optional but useful)

Important:

This is not “anywhere in 100 before + anywhere in 100 after across different windows”.

Each window is explicitly tied to an occurrence of the node.

Quad (node-centred quad)

node + top 3 co-lemmas (by weight) within a time slice OR within selected scope (configurable below)

Implement time slicing as in Step 7:

year: year_est else year_mid else year_min

decade: decade else decade_num
Missing → "Unknown"

Now implement:
