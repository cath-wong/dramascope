4) Core semantic computations (interpretable)
A) Co-occurrence association around a target term

If target term is empty → show instruction message.

Else:

Filter speeches by global scope/filters.

For each speech:

tokenise

find occurrences of target term

collect co-occurring tokens within the speech (simple: all tokens in that speech excluding the target; or, better: within ±N tokens around each occurrence where N is fixed like 10 — choose one and document it in UI; default N=10 is fine)

Compute:

unigram counts across corpus (within the same filtered subset)

cooc counts for tokens that co-occur with target (within the chosen basis)

Score:

Prefer PMI:

p(x,y) = cooc(x,y) / totalCoocEvents

p(x) = count(x) / totalTokens

p(y) = count(y) / totalTokens

PMI = log2(p(x,y)/(p(x)p(y)))

If PMI too fiddly, implement log-likelihood or keep count, but PMI is preferred.

Output table (Top-N by score):

term

cooc_count

score

speech_hits (number of speeches contributing)

CSV export required.
