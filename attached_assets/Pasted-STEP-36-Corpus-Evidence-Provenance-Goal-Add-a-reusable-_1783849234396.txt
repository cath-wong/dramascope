STEP 36 — Corpus Evidence & Provenance

Goal

Add a reusable Corpus Evidence panel to the Semantic Dashboard that allows every selected analytical object to be traced back to the corpus from which it was derived.

This step introduces NO new analytical metrics.

Instead, it provides transparent provenance for expression candidates, expression families, conventionalisation candidates, and diachronic objects.

The purpose is to answer:

"Where does this result come from?"


IMPORTANT

Do NOT modify:

- Lexical tab
- Discursive tab
- expression extraction
- family construction
- conventionalisation calculations
- diachronic calculations
- preprocessing
- tokenisation
- lemmatisation
- stoplists

Do NOT add:

- new metrics
- new rankings
- new algorithms
- new statistical measures
- new scoring systems

This is an evidence/provenance layer only.


Scope

Apply ONLY to:

client/src/pages/Analysis.tsx

Focus ONLY on:

SemanticTab

Reuse one shared component wherever possible.


Design Philosophy

Every selected analytical object should be traceable back to its corpus evidence.

Researchers should always be able to inspect:

• which plays

• how often

• which expressions

generated the higher-level analytical object.


Implementation

Create one reusable component:

CorpusEvidencePanel


The component should accept one of:

• expression candidate

• expression family

• conventionalisation candidate

• diachronic item


and display evidence accordingly.

Expected Result

Every analytical object throughout the Semantic Dashboard should now be traceable back to:

• individual plays

• frequencies

• underlying expressions

without leaving the dashboard.

Researchers should no longer need to switch to external corpus tools simply to discover where a result originates.
