1) Stats to compute (Dashboard)
A. Corpus scope rules

Use the global UI state from Step 2:

If corpusScope = full: use all rows

If corpusScope = play: filter by selectedPlayTitle (match title)

Apply optional genre filter if present

Apply excludeStageDirections only to lines dataset if implemented; otherwise ignore for now but keep UI label

B. Required KPI metrics

Compute and show as KPI cards at top of Dashboard:

Plays included

Unique count of title within the currently selected scope (use lines dataset as source of truth)

Total lines rows

number of rows in filtered lines dataset

Total speeches rows

number of rows in filtered speeches dataset

Total tokens (lines)

Tokenise text_norm in lines:

token count = whitespace split after basic normalisation (lowercase + trim)

do NOT lemmatise yet (that’s fine later)

ignore empty tokens

Total tokens (speeches)

Token count from speeches:

use text_raw (or normalised) whitespace split

ignore empty tokens

Types + TTR
Compute separately for lines tokens and speeches tokens:

types = unique token count

TTR = types / tokens (display 3 decimals)

Optional (only if easy):

lexical density proxy (e.g. % tokens not in stoplist) — but keep optional
