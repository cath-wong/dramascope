STEP 39A — Lexical Content Words Only Mode

Goal

Add a Lexical-only "Content Words Only" view to the Lexical Dashboard.

This feature is completely independent of the existing Discursive implementation.

It must NOT alter the Semantic or Discursive tabs.

It is intended to improve traditional lexical frequency analysis by allowing users to suppress grammatical function words without changing the underlying lexical stoplist or expression extraction infrastructure.


IMPORTANT

Do NOT modify:

- SemanticTab
- DiscursiveTab
- processTokens()
- getStoplist()
- expression extraction
- family construction
- concept modelling
- discursiveFilter.ts
- shared linguistic utilities unless absolutely necessary

Do NOT expand the shared stoplist.

Do NOT change existing Semantic behaviour.

This is a Lexical-tab-only feature.


Scope

Apply ONLY to:

client/src/pages/Analysis.tsx

Create a new helper file ONLY if needed.

Do NOT touch the existing Discursive content-word implementation.


Design Principle

The Lexical Dashboard should support two complementary lexical views.

All Words

Traditional lexical analysis after the existing stoplist has optionally been applied.

Content Words Only

Further suppresses high-frequency grammatical words to foreground lexical content.

This is a display/filtering option.

It is NOT a replacement for the stoplist.


Implementation

1.

Keep the existing Stoplist checkbox unchanged.

It continues to use the existing shared getStoplist() exactly as before.

No behaviour changes.


2.

Add a new segmented toggle beneath the Stoplist/Lemma controls.

3.

Create a new lexical-only filter.

Preferred location:

Implement something similar to:

isLexicalContentWord(token)

This filter is completely independent from:

- getStoplist()
- discursiveFilter.ts

Do NOT import or reuse the Discursive filter directly.

The lexical list should be appropriate for traditional frequency-list analysis.
