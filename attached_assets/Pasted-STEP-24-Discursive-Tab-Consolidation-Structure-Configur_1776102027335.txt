Goal

Consolidate the existing Discursive tab into a coherent analytical dashboard organised around four outputs:

1. Constellation Snapshot
2. Cluster / Configuration Profile
3. Concept Behaviour Summary
4. Diachronic Change View

This step must NOT add new analytical features or change the modelling logic.
It is a UI and interpretation-layer consolidation step only.

IMPORTANT

Do NOT modify, revert, overwrite, or refactor any manually edited code.
Do NOT change:
- quad extraction
- stoplists
- tokenisation
- lemmatisation
- Sankey logic
- subcluster generation logic
- participation classification logic
- thresholds
- CSV logic already added
- any existing manual fixes in Analysis.tsx

This step must preserve all current computations and outputs.

- client/src/pages/Analysis.tsx

- section headings

Implementation Steps

1. Keep the top-level Discursive tab exactly as a single tab.
   Do NOT add new tabs.

2. Reorganise the visible layout of the Discursive tab into four named sections, in this order:

   A. Constellation Snapshot
   B. Cluster / Configuration Profile
   C. Concept Behaviour Summary
   D. Diachronic Change View

3. Under “Constellation Snapshot”, place:
   - Sankey Traffic (Synchronic Overview)
   - Top Quads / Quad Drill-Down if already visually tied to the snapshot view

4. Under “Cluster / Configuration Profile”, place:
   - Constellation Subclusters
   - Recurring Co-Terms
   - Top Co-Term Pairings

5. Under “Concept Behaviour Summary”, place:
   - Participation Summary block (from Step 23)
   - Quad Subcluster Participation panel
   - Core vs Peripheral Quads

6. Under “Diachronic Change View”, place:
   - Diachronic Stability
   - Temporal Concept Flow

7. Keep existing controls and panel internals intact unless a tiny spacing or heading adjustment is needed.

8. Add short section headings and 1-line descriptive subtitles for each section.
   Use plain analytical language, for example:
   - Constellation Snapshot → “Cross-sectional view of the node lemma’s current constellation structure.”
   - Cluster / Configuration Profile → “Configuration of recurring co-terms and thematic grouping within the constellation.”
   - Concept Behaviour Summary → “How the concept behaves structurally across clusters, cores, and peripheral zones.”
   - Diachronic Change View → “How the concept’s structure and prominence vary across time slices.”

9. Do NOT invent new metrics in this step.

10. If needed for readability, place lower-priority tables inside Collapsible components, but ONLY if this can be done with minimal risk.
    Preferred candidates for optional collapse:
    - Top Co-Term Pairings
    - full Quad Subcluster Participation table
    Do NOT collapse Sankey, Constellation Subclusters, or Temporal Concept Flow.

11. Preserve the existing data/export functionality.

12. Do NOT remove any current panels in this step.
    If something is demoted visually, it must still remain accessible.
