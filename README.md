# DramaScope

**DramaScope** is an interactive digital humanities research platform for the lexical, semantic and discursive analysis of Early Modern English drama.

Developed by **Dr Catherine Wong** (University of Sheffield), DramaScope supports exploratory analysis of historical literary corpora through an integrated suite of computational tools designed for researchers, educators and students.

## Features

- Lexical analysis (word frequency, collocations, KWIC)
- Semantic analysis and expression tracking
- Discursive visualisation
- Interactive dashboards
- Shakespeare demonstration corpus
- Web-based interface requiring no installation
