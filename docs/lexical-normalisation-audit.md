# Lexical Normalisation Audit

This document preserves the findings of the diagnostic audit conducted during the development of DramaScope v1.1. It examines historical spelling variations and potential lemma artefacts generated by the application's lightweight lemmatisation pipeline when processing the expanded Early Modern drama corpus. 

This audit is purely diagnostic; no corpus data or analytical processing behaviours were modified as part of this audit, and all original spelling representations remain preserved intact in the corpus source CSV files and textual evidence.

### Unsafe Behaviours Found in `lightLemmatize()`

1. **Trailing Apostrophes Left by Possessives/Contractions (Category C)**:
   - **The Problem**: Words ending in `'s` (e.g., `love's`, `devil's`, `she's`, `lady's`) match the generic final-s plural rule. The lemmatiser strips the `s` but leaves the apostrophe behind, resulting in trailing-apostrophe tokens like `love'`, `devil'`, `she'`, and `lady'`.
   - **Why it's unsafe**: These trailing-apostrophe forms (e.g. `love'`) are treated by the dashboard as separate, unique words distinct from their root forms (e.g. `love`), inflating the vocabulary counts and fragmenting collocates and semantic results.
   - **Recommendation**: Add logic to either handle `'s` explicitly or strip trailing apostrophes from tokens at the end of the `lightLemmatize()` step.

2. **Aggressive `ies -> y` Reduction on Short Verbs (Category C)**:
   - **The Problem**: The `ies` rule unconditionally targets all tokens ending in `ies`, converting them to `y` (e.g., `dies` -> `dy`, `lies` -> `ly`, `ties` -> `ty`).
   - **Why it's unsafe**: This creates illegible 2-letter strings (`dy`, `ly`, `ty`) for common short verbs instead of their true base forms (`die`, `lie`, `tie`).
   - **Recommendation**: Guard the `ies` rule so it only applies if the resulting token has a length greater than 2 (or protect these common verbs explicitly).

3. **Malformed Adjectives/Nouns Ending in `ed` or `ing` (Category C)**:
   - **The Problem**: Words ending in `eed` (e.g., `speed`, `indeed`, `bleed`, `breed`) and non-present-participle words ending in `ing` (e.g., `nothing`, `anything`, `something`, `everything`, `changeling`) fall prey to the generic `ed` and `ing` rules.
   - **Why it's unsafe**: They get truncated into non-words (`spe`, `inde`, `ble`, `bre`, `noth`, `anyth`, `someth`, `everyth`, `changel`), which pollute the lexical frequency lists.
   - **Recommendation**: Explicitly safeguard these high-frequency non-verbs/nouns in the lemmatiser.
